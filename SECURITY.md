# Security Policy

## Reporting a vulnerability

If you discover a potential security vulnerability in this project, please report it privately before opening a public issue.

Send a detailed report to:

**dfournarakos567@gmail.com**

Please include:

- A clear description of the vulnerability.
- The affected file, component or URL.
- Steps to reproduce the issue.
- Any relevant screenshots, logs or proof of concept.
- The potential impact, if known.

Please do not include passwords, private keys or other sensitive personal data in the report.

## Response

I will review valid reports and, where possible, acknowledge receipt and provide an update after investigating the issue. Please allow reasonable time for assessment and remediation before publicly disclosing the vulnerability.

## Scope

This policy applies to the source code and website contained in this repository. Third-party services, CDNs and external websites are outside the direct scope of this project.
